Topik D • Pengenalan & Cara Penggunaan

Mengenal CSS & 3 Cara Penggunaannya

🎨
Apa itu CSS?

CSS adalah singkatan dari Cascading Style Sheets (Lembar Gaya Bertingkat). CSS adalah bahasa yang digunakan untuk mengatur tampilan visual, warna, ukuran, tata letak (layout), dan keindahan sebuah halaman web yang strukturnya telah dibuat menggunakan HTML.

HTML (Struktur & Isi) + CSS (Tata Rias & Desain) = Website yang Rapi & Menarik! ✨
💡

Mengapa HTML dan CSS Harus Dipisahkan? (Prinsip Ahli Web)

Bayangkan kamu sedang mempersiapkan diri berangkat ke sekolah:

🧍
HTML = Tubuh Manusia / Kerangka Rumah

Menentukan ada kepala, badan, tangan, dan kaki. Pada web: menentukan ada teks judul, paragraf, gambar, dan tabel.

👔
CSS = Seragam, Sepatu & Aksesoris Rapi

Memakaikan kemeja putih berlogo MTsN, dasi rapi, celana biru, sepatu mengkilap, dan tatanan rambut keren. Tanpa pakaian yang rapi (CSS), tubuh (HTML) akan terlihat sangat polos dan canggung!

Anatomi Sebuah Aturan CSS (CSS Rule Set)

Setiap aturan penulisan CSS terdiri dari 3 bagian utama: Selector, Property, dan Value.

SELECTOR h1 Siapa elemen HTML yang ingin kita hias?
{
PROPERTY color Sifat apa yang ingin diubah?
:
VALUE blue Mau diubah menjadi apa?
;
}
⚠️ Catatan Penting: Jangan lupa tanda titik dua (:) sebagai pemisah dan titik koma (;) untuk mengakhiri setiap aturan properti!

3 Cara Menggunakan CSS pada Dokumen HTML

Ada 3 metode untuk menerapkan CSS ke dalam halaman web. Setiap metode memiliki tempat penulisan, kelebihan, dan kegunaannya masing-masing:

Cara 1 (Sangat Dianjurkan) ⭐⭐⭐ STANDAR INDUSTRI

1. External CSS (Berkas Terpisah)

Kode CSS ditulis di dalam berkas terpisah berekstensi .css (contoh: style.css), lalu dihubungkan ke berkas HTML menggunakan tag <link> di dalam bagian <head>.

File: index.html
<head>
    <title>Halaman Siswa</title>
    <!-- Menghubungkan file CSS -->
    <link rel="stylesheet" href="style.css">
</head>
File: style.css
body {
    background-color: #f0f4f8;
    font-family: Arial, sans-serif;
}
h1 {
    color: #1e3a8a;
}
✅ Kelebihan: Kode sangat rapi, dan 1 file style.css dapat digunakan oleh puluhan bahkan ratusan halaman web secara bersamaan!
❌ Kekurangan: Memerlukan 2 berkas terpisah di dalam folder komputer.
Cara 2 (Khusus 1 Halaman) ⭐⭐ TERTANAM DI HEAD

2. Internal CSS (Tag <style> di dalam <head>)

Kode CSS diletakkan langsung di dalam dokumen HTML itu sendiri, tepatnya di dalam tag <style> ... </style> di antara tag <head>.

File: index.html
<head>
    <title>Halaman Khusus</title>
    <style>
        h1 {
            color: #059669;
            text-align: center;
        }
        p {
            font-size: 16px;
        }
    </style>
</head>
✅ Kelebihan: Praktis jika kita hanya membuat 1 halaman tunggal yang memiliki gaya unik dan tidak dipakai halaman lain.
❌ Kekurangan: Tidak bisa dipakai bersama oleh halaman HTML lain; jika ada 10 halaman maka kode CSS harus dicopy 10 kali.
Cara 3 (Gaya Langsung di Tag) ⭐ ATRIBUT STYLE

3. Inline CSS (Atribut style="..." pada Tag)

Kode CSS ditulis langsung menempel pada tag HTML yang bersangkutan menggunakan atribut style="...".

File: index.html
<!-- Atribut style langsung menempel di elemen -->
<h1 style="color: red; text-align: center; font-size: 26px;">
    Biodata Siswa
</h1>

<p style="background-color: yellow; padding: 6px; font-weight: bold;">
    Teks ini diberi stabilo kuning darurat.
</p>
✅ Kelebihan: Sangat cepat untuk uji coba darurat atau memberi warna khusus pada satu elemen spesifik.
❌ Kekurangan: Membuat kode HTML sangat berantakan, sulit dirawat, dan tidak dianjurkan untuk proyek besar!

Tabel Rangkuman & Urutan Kekuatan (Prioritas Cascading)

Jika ada elemen yang diatur oleh ketiga metode sekaligus, siapakah yang akan menang dan tampil di layar?

Metode CSS Lokasi Penulisan Tingkat Kekuatan (Prioritas) Rekomendasi Penggunaan
1. Inline CSS Langsung di tag elemen (style="...") Paling Kuat (Prioritas 1) Hanya untuk tes cepat 1 elemen
2. Internal CSS Di dalam tag <style> di <head> Menengah (Prioritas 2) Untuk 1 halaman khusus
3. External CSS Di berkas style.css terpisah Standar (Prioritas 3)* Paling Dianjurkan untuk Semua Web
💡 Prinsip Cascading Sederhana: "Siapa yang paling dekat menempel pada elemen HTML, perintah gayanya yang akan diprioritaskan oleh peramban!"
Topik E • Properti Utama

Properti-Properti Penting CSS yang Wajib Dikuasai

Agar kamu bisa membuat website yang indah seperti para programmer profesional, berikut adalah katalog properti penting CSS yang paling sering digunakan dalam kehidupan nyata:

🎯 KELOMPOK 1: SELECTOR (PEMILIH ELEMEN)
1. Element Selector

Selector Tag / Elemen

Memilih semua elemen yang memiliki nama tag yang sama di seluruh halaman.

p {
    color: #334155;
}

Semua tag <p> akan otomatis berwarna abu-abu gelap.

2. Class Selector (.)

Selector Kelas (Tanda Titik)

Memilih elemen yang memiliki atribut class="...". Bisa dipakai berulang kali.

.kartu-siswa {
    background: white;
    border-radius: 10px;
}

Dipanggil di HTML dengan: <div class="kartu-siswa">

3. ID Selector (#)

Selector ID (Tanda Pagar)

Memilih satu elemen khusus yang memiliki atribut id="..." unik di halaman.

#biodata-utama {
    border: 2px solid blue;
}

Dipanggil di HTML dengan: <div id="biodata-utama">

4. Pseudo-Class (:hover)

Efek Sentuhan Kursor (:hover)

Memberi animasi perubahan gaya saat kursor mouse melayang di atas elemen.

button:hover {
    background-color: #1d4ed8;
    transform: scale(1.05);
}
✍️ KELOMPOK 2: TEKS & TIPOGRAFI
color

Warna Teks

Mengubah warna huruf. Bisa menggunakan nama warna (blue) atau kode HEX (#2563eb).

h1 { color: #2563eb; }
Teks Biru Modern (#2563eb)
font-family

Jenis Huruf (Font)

Menentukan jenis huruf yang digunakan agar tulisan terlihat modern dan nyaman dibaca.

body { font-family: Arial, sans-serif; }
Font Arial Bersih Tanpa Gerigi
font-size & font-weight

Ukuran & Ketebalan Teks

font-size mengatur besar teks (px), font-weight mengatur ketebalan (bold).

h2 { 
    font-size: 24px; 
    font-weight: bold; 
}
Ukuran 24px Tebal
text-align & text-decoration

Perataan & Dekorasi Teks

text-align mengatur posisi (center/left/right), text-decoration: none; menghapus garis bawah link.

a { 
    text-decoration: none; 
}
Tautan Tanpa Garis Bawah
📦 KELOMPOK 3: CSS BOX MODEL & PENGATURAN JARAK
Box Model: Margin, Border, Padding, Content

Memahami Konsep Kotak di Setiap Elemen Web

Di dalam browser, setiap elemen HTML (judul, gambar, tombol, kotak) dianggap sebagai sebuah KOTAK berlapis-lapis:

1. MARGIN (Jarak Luar)

Jarak di bagian luar batas kotak dengan elemen lain di sekelilingnya. Memberi ruang bernapas antar elemen.

div { margin: 20px; }
2. BORDER (Garis Tepi)

Garis bingkai pembatas kotak (ketebalan, tipe garis, warna).

div { border: 2px solid #2563eb; }
3. PADDING (Jarak Dalam)

Jarak antara isi teks/gambar dengan garis tepi kotak. Membuat teks tidak menempel sesak di pinggir.

div { padding: 16px; }
MARGIN (Jarak Luar)
BORDER (Garis Tepi)
PADDING (Jarak Dalam)
ISI KONTEN (Teks/Gambar)
border-radius

Sudut Melengkung (Rounded Corners)

Membuat sudut kotak menjadi tumpul dan modern, tidak kaku runcing 90 derajat.

div { 
    border-radius: 12px; 
}
Kotak dengan Sudut 12px Melengkung
max-width & margin: 0 auto;

Trik Menengahkan Halaman

Trik paling populer desainer web untuk membuat kartu konten berada persis di tengah layar horizontal:

.container {
    max-width: 650px;
    margin: 0 auto; /* Otomatis Tengah */
}
Konten Otomatis Center & Responsif!
📊 KELOMPOK 4: PROPERTI KHUSUS TABEL & FORMULIR
border-collapse & th/td

Mempercantik Tabel Modern

border-collapse: collapse; menyatukan garis ganda kuno menjadi 1 garis ramping.

table {
    width: 100%;
    border-collapse: collapse;
}
th, td {
    padding: 8px 12px;
    border: 1px solid #cbd5e1;
}
th {
    background-color: #1e3a8a;
    color: white;
}
input, button, :focus

Mempercantik Formulir Input

Memberi padding, border rounded pada input, dan efek fokus bersinar saat diketik:

input[type="text"] {
    padding: 8px 12px;
    border: 1px solid #94a3b8;
    border-radius: 6px;
}
input:focus {
    border-color: #2563eb;
    outline: none;
}

7 Langkah Strategis Mempercantik Kode Tersebut:

1
Membungkus Kanvas Halaman (body & container)

Mengubah background halaman menjadi abu-abu lembut (#f0f4f8) dan membungkus seluruh isi ke dalam kartu putih berpusat di tengah dengan max-width: 680px; margin: 30px auto; padding: 30px; border-radius: 16px; box-shadow: ....

2
Memperindah Judul & Teks Pengenal

Memberi warna biru elegan pada h1 (#1e3a8a), memberi garis bawah aksen gradasi, serta mengganti jenis font ke 'Segoe UI', Arial, sans-serif agar tulisan enak dibaca.

3
Menyulap Link ChatGPT Menjadi Tombol Keren

Tautan <a href="https://chatgpt.com/"> yang awalnya biru bergaris bawah kita ubah menjadi tombol hijau ChatGPT (#10a37f) dengan text-decoration: none; padding: 9px 18px; border-radius: 8px; font-weight: bold; lengkap dengan efek :hover!

4
Merapikan Foto Kamad MTsN 5 Sumedang

Daripada menggunakan width="10%" yang bisa gepeng, di CSS kita atur lebarnya menjadi pasti (misal 130px), sudut membulat border-radius: 12px;, dan bingkai putih berbayang tipis.

5
Mengemas Hobi & Cita-Cita Menjadi Kartu Pastel

List hobi (<ul>) dan cita-cita (<ol>) diberi latar belakang kartu lembut pastel (kuning hangat untuk hobi, hijau segar untuk cita-cita) dengan padding yang rapi.

6
Merombak Tabel Riwayat Pendidikan

Menghapus atribut kuno border="1" dan menggantinya dengan aturan CSS modern: border-collapse: collapse;, latar header kolom <th> biru dongker, dan sel <td> yang diberi jarak lega.

7
Merapikan Formulir Masukan

Kotak input diberi border halus #cbd5e1, efek bersinar saat diklik (:focus), dan tombol Kirim diberi warna hijau dengan transisi lembut saat disentuh kursor mouse.

Mengenal JavaScript & Konsep-Konsep Penting

⚡
Apa itu JavaScript?

JavaScript adalah bahasa pemrograman yang digunakan untuk memberikan aksi, logika, dan interaksi pada halaman web. Tanpa JavaScript, halaman web ibarat koran atau poster yang hanya bisa dilihat dan dibaca secara pasif. Dengan JavaScript, halaman web menjadi aplikasi hidup yang bisa merespons klik mouse, menghitung nilai, memvalidasi formulir, dan menampilkan animasi interaktif!

HTML (Kerangka) + CSS (Tata Rias) + JavaScript (Otak & Aksi) = Website Interaktif Modern! 🚀
💡

Analogi Rumah Modern (HTML + CSS + JavaScript):

Mari kita pahami pembagian tugas ketiga teknologi web ini melalui perumpamaan rumah cerdas:

🧱
HTML: Bangunan Fisik

Membuat pondasi, tembok kamar, kusen pintu, dan jendela kaca.

🎨
CSS: Dekorasi & Cat

Memberi warna cat tembok, tirai jendela yang cantik, dan susunan sofa yang rapi.

⚡
JavaScript: Listrik & Aksi Cerdas

Bel pintu yang berdering saat dipencet, saklar lampu otomatis, pendingin ruangan (AC), dan pintu geser otomatis saat orang mendekat!

3 Cara Menghubungkan JavaScript ke Dokumen HTML

Mirip seperti CSS, ada 3 cara untuk memasang kode JavaScript ke dalam dokumen web:

Cara 1 (Sangat Dianjurkan) ⭐⭐⭐ STANDAR INDUSTRI

1. External JavaScript (Berkas script.js Terpisah)

Kode JavaScript ditulis di berkas terpisah berekstensi .js (contoh: script.js), lalu dihubungkan menggunakan tag <script src="script.js"></script> sebelum tag penutup </body>.

File: index.html (Sebelum </body>)
<!-- Menghubungkan file JavaScript eksternal -->
<script src="script.js"></script>
</body>
✅ Kelebihan: Paling rapi, mudah diperbaiki, dan 1 berkas script bisa dipakai di banyak halaman web sekaligus.
Cara 2 (Khusus 1 Halaman) ⭐⭐ TERTANAM DI HTML

2. Internal JavaScript (Tag <script>)

Kode JavaScript diletakkan langsung di dalam tag <script> ... </script> di dalam dokumen HTML itu sendiri.

File: index.html
<script>
    alert("Selamat datang di web MTsN 5 Sumedang!");
</script>
✅ Kelebihan: Praktis untuk kode singkat tanpa perlu membuat file baru.
Cara 3 (Event Handler Langsung) ⭐ ATRIBUT ONCLICK

3. Inline JavaScript (Atribut Event pada Elemen)

Kode JavaScript ditulis langsung menempel pada atribut tag HTML seperti onclick="...".

File: index.html
<button onclick="alert('Tombol berhasil diklik!')">Klik Saya</button>
✅ Kelebihan: Cepat untuk percobaan satu tombol sederhana.

6 Konsep Kunci JavaScript yang Wajib Dikuasai

Berikut adalah materi inti JavaScript yang menjadi bekal penting dalam membangun interaksi website:

1

Variabel (let & const)

Variabel adalah wadah atau kotak berlabel di memori komputer untuk menyimpan data (seperti nama, nilai, atau status) agar bisa digunakan berulang kali. 

// let: nilai data bisa diubah nanti
let nama = "Deden Juliandi";
let umur = 15;
let apakahLulus = true;

// const: nilai data tetap (tidak boleh diubah)
const namaSekolah = "MTsN 5 Sumedang";
Kotak let: nama "Deden Juliandi"
Kotak const: namaSekolah "MTsN 5 Sumedang"
💡 Tipe Data Dasar: String (teks berapit tanda kutip), Number (angka tanpa kutip), dan Boolean (nilai kebenaran true atau false).
2

Dialog Interaktif Pengguna & console.log()

JavaScript menyediakan 3 jendela dialog pop-up bawaan browser untuk berkomunikasi dengan pengguna, serta console.log() untuk catatan programmer: 

// 1. alert: menampilkan pesan pengumuman
alert("Ujian Informatika dimulai!");

// 2. prompt: meminta masukan teks/nama
let nama = prompt("Siapa nama lengkapmu?");

// 3. confirm: meminta persetujuan OK/Batal (true/false)
let yakin = confirm("Apakah kamu yakin ingin mengirim data?");

// 4. console.log: catatan programmer di konsol
console.log("Data siswa telah diperiksa");
Coba Dialog Interaktif Ini:
3

Fungsi (Function)

Fungsi adalah kumpulan perintah yang dibungkus dan diberi nama, agar bisa dijalankan berkali-kali kapan pun kita membutuhkannya. 

// Membuat fungsi
function sapaSiswa(nama) {
    alert("Selamat datang di kelas Informatika, " + nama + "!");
}

// Memanggil fungsi
sapaSiswa("Andi");
sapaSiswa("Siti");
4

Event Handler (onclick)

Event adalah peristiwa yang terjadi di halaman web saat pengguna berinteraksi (misalnya: mengeklik tombol, mengetik di form, atau menggerakkan mouse). 

<!-- Hubungkan klik tombol dengan fungsi JS -->
<button onclick="sapaDeden()">
    👋 Sapa Deden!
</button>
Saat tombol diklik, browser akan langsung memanggil fungsi sapaDeden()!
5

Manipulasi DOM Sederhana (Jembatan JS ke HTML & CSS)

DOM (Document Object Model) adalah cara JavaScript mengakses dan mengubah isi teks atau gaya CSS pada halaman web secara langsung tanpa perlu mereload halaman! 

// 1. Memilih elemen HTML berdasarkan ID-nya
let judul = document.getElementById("judulUtama");

// 2. Mengubah teks elemen dari JavaScript
judul.innerText = "Judul Telah Berubah!";

// 3. Mengubah gaya CSS langsung dari JavaScript
judul.style.color = "green";

// 4. Menghidupkan Mode Gelap dengan toggle class
document.body.classList.toggle("mode-gelap");
Teks Asli Sebelum Diubah
6

Percabangan Logika (if...else)

Percabangan if...else digunakan untuk mengambil keputusan berdasarkan kondisi tertentu (jika kondisi benar lakukan A, jika salah lakukan B). 

let nilai = 85;

if (nilai >= 75) {
    console.log("Selamat, kamu Lulus! 🎉");
} else {
    console.log("Ayo semangat belajar lagi ya! 📚");
}
Kondisi: Nilai >= 75 ?
Benar → LULUS Salah → REMEDIAL

📌 Intisari Materi Penting yang Wajib Diingat:

🌐 1. HTML (Kerangka & Struktur Web)
✓HTML digunakan untuk membuat struktur dan kerangka isi halaman web.
✓Struktur Dasar terdiri dari <!DOCTYPE html>, <html>, <head> (judul tab), dan <body> (isi yang terlihat).
✓<h1> hingga <h3> untuk membuat judul bertingkat dari yang paling besar ke subjudul.
✓<p> digunakan untuk membuat paragraf teks tulisan.
✓<a href="..."> digunakan untuk membuat tautan link antarpageweb.
✓<img src="..." alt="..."> digunakan untuk menampilkan gambar ke halaman web.
✓<ul> untuk daftar dengan bullet titik, sedangkan <ol> untuk daftar dengan nomor urut.
✓<table> untuk membuat tabel data dengan baris <tr>, judul kolom <th>, dan sel data <td>.
✓<form> sebagai wadah formulir input data dengan <label>, <input>, dan tombol <button>.
🎨 2. CSS (Tata Rias, Warna & Desain)
✓CSS (Cascading Style Sheets) digunakan untuk mengatur keindahan, warna, font, dan tata letak halaman web.
✓Anatomi CSS: Terdiri dari Selector { Property: Value; } yang dipisahkan titik dua dan diakhiri titik koma.
✓3 Cara Penggunaan CSS: External (berkas terpisah via <link>), Internal (tag <style> di head), dan Inline (atribut style="...").
✓Prioritas Cascading: Inline CSS > Internal / External CSS (siapa paling dekat menempel di elemen, perintahnya yang menang).
✓Selector: Tag (h1), Class (.nama-kelas dengan tanda titik), ID (#nama-id dengan tanda pagar), dan efek kursor (:hover).
✓color untuk warna teks, dan background-color untuk warna latar belakang kotak atau halaman.
✓font-family untuk menentukan jenis font modern, dan font-size untuk mengatur ukuran teks.
✓text-decoration: none; kunci untuk menghilangkan garis bawah biru bawaan link agar bisa disulap jadi tombol modern.
✓CSS Box Model: margin (jarak bagian luar) vs padding (jarak bagian dalam) vs border (garis tepi pembatas).
✓border-radius membuat sudut kotak menjadi melengkung/membulat (efek rounded modern).
✓max-width: 650px; margin: 0 auto; trik jitu membuat kartu konten berada persis di tengah layar secara horizontal.
✓border-collapse: collapse; menyatukan garis ganda tabel kuno menjadi 1 garis rapi dan modern.
⚡ 3. JavaScript (Otak, Logika & Aksi Interaktif)
✓JavaScript adalah bahasa pemrograman yang memberi aksi, logika, dan interaksi agar web menjadi hidup.
✓3 Cara Pasang JS: External (<script src="..."> sebelum </body>), Internal (<script>), dan Inline (event onclick).
✓let untuk membuat variabel yang datanya bisa diubah, sedangkan const untuk data yang bersifat tetap/konstan.
✓console.log() untuk mencetak pesan/catatan programmer di balik layar peramban.
✓alert() memunculkan pesan pengumuman pop-up, sedangkan prompt() meminta masukan ketikan nama/data dari pengguna.
✓confirm() memunculkan dialog persetujuan dengan pilihan tombol OK (true) atau Batal (false).
✓Fungsi (function): Kumpulan perintah bernama yang dijalankan saat dipanggil, misal dipicu oleh event onclick pada tombol.
✓Manipulasi DOM: document.getElementById('id') untuk memilih elemen, .innerText untuk ganti teks, dan .classList.toggle() untuk fitur Dark Mode!
✓Percabangan if...else: Mengambil keputusan logis (misal memeriksa apakah form sudah diisi lengkap atau belum).
🏫 4. Studi Kasus Trio Web (Biodata MTsN 5 Sumedang)
✓HTML: Membangun struktur biodata Deden Juliandi (judul, identitas kelas 9, foto kamad, link ChatGPT, hobi, cita-cita, tabel riwayat, dan form).
✓CSS: Mengubah tampilan kaku menjadi kartu putih berbayang halus di tengah, tombol ChatGPT hijau, sudut foto membulat, dan tabel modern.
✓JavaScript: Menyalakan aksi nyata: tombol sapa pengunjung dengan prompt(), saklar Mode Gelap dengan classList.toggle(), tambah hobi baru secara dinamis, dan validasi form dengan if...else!
